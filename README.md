## 🚀 Featured Projects

**QR-Tagged Asset Tracking Platform**
A field-to-dashboard system for managing distribution and power-transformer assets — QR-tagged inventory, validation workflows, and live tracking. Built with Next.js + Supabase, deployed on Vercel.

**Asset Harmonization System**
A platform that consolidates asset submissions from multiple departments into a single, trusted source for network planning and operations.

**Geospatial Analytics Dashboards**
Interactive dashboards visualizing large feeder and network datasets (16k+ georeferenced points), with authentication, audit logging, and role-based access.

**Automated Geospatial Pipelines**
Python tooling (ArcPy / GeoPandas) for feeder coordinate extraction, geodatabase management, and regulatory reporting.
